   function getNext4HCandle() {

     let nextHour = Math.ceil((utcHour + (mins>0||secs>0?1:0))/4)*4;

6-STEP AI ANALYSIS ENGINE (COMPLETE LOGIC)
═════════════════════════════════════════════════════════════════════════════

STEP 1: MACRO FILTER (25% weight)
─────────────────────────────────
Checks: CPI, Oil prices, Geopolitical risk, S&P 500
Scorecard:
  • CPI > 3.0 → -25 (hawkish, bad for BTC)
  • Oil > 90 → -20 (risk-off environment)
  • Geo = CRITICAL → -20 (war/crisis risk)
  • S&P <-0.5% → -10 (stocks down, flight to safety)
  • S&P >+0.5% → +10 (stocks up, risk-on)
Output: macroScore (-65 to +10), macroOutlook (BEARISH/NEUTRAL/BULLISH)


STEP 2: TECHNICAL CONFIRMATION (30% weight)
────────────────────────────────────────────
Checks: Price vs SMAs, RSI, MACD, ADX, Death Cross
Scorecard:
  • Price < SMA50 → -20
  • Price < SMA100 → -15
  • Price > SMA200 → +20 (else -25)
  • Death Cross → -20
  • RSI < 30 → +30 (oversold = bouncy)
  • RSI 30-40 → +10
  • RSI > 70 → -30 (overbought)
  • MACD < 0 → -10 (bearish)
  • ADX > 60 → -15 (trend exhaustion)
Output: techScore (-115 to +40), techOutlook (BEARISH/NEUTRAL/BULLISH)


STEP 3: ON-CHAIN & SENTIMENT (30% weight)
──────────────────────────────────────────
Checks: MVRV Z-Score, SOPR, Exchange reserves, Fear & Greed
Scorecard:
  • MVRV < 1.0 → +25 (fair value)
  • MVRV > 3.0 → -25 (overvalued)
  • SOPR < 1.5 → +20 (no panic selling)
  • Reserves < 2.5M → +20 (supply shock, bullish)
  • FG < 20 → +25 (extreme fear = opportunity)
  • FG > 75 → -20 (extreme greed = caution)
Output: onchainScore (-25 to +90), onchainOutlook (BEARISH/NEUTRAL/BULLISH)


STEP 4: DERIVATIVES ANALYSIS (15% weight)
──────────────────────────────────────────
Checks: Funding rates, Open Interest (short squeeze setup)
Scorecard:
  • Funding < -0.01% → +40 (crowded shorts vulnerable)
  • Funding < -0.02% → +20 extra (very negative)
  • OI > $20B → +20 (high leverage)
  • OI > $24B → +10 extra (extreme leverage)
Calculates: squeezeRisk = min(95, max(5, derivScore + 10))
Output: derivScore (0-100), squeezeRisk (5-95%)


STEP 5: SIGNAL COMPUTATION
──────────────────────────
Combines all scores with weights:
  totalScore = (macro×0.25) + (tech×0.30) + (onchain×0.30) + (deriv×0.15)

Signal determination:
  • totalScore > 25 → BUY signal
  • totalScore < -25 → SELL signal
  • else → HOLD signal

Confidence calculation:
  • If BUY: confidence = min(92, 60 + totalScore)
  • If SELL: confidence = min(92, 60 + abs(totalScore))
  • If HOLD: confidence = min(75, 50 + abs(totalScore))

OVERRIDE (if True, force BUY with +15 confidence):
  if (FG < 15 AND funding < -0.015 AND price within 2% of SMA200)
    → Force BUY (market is too fearful + setup too perfect)

Timeframe:
  • IMMEDIATE: If BUY and price already in entry zone
  • NEXT_4H: If BUY and price needs to await next candle
  • WAIT: If HOLD or SELL


STEP 6: ZONES & OUTPUT
──────────────────────
Entry Bottom: SMA200 × 1.001 (just above key support)
Entry Top: EMA50 × 1.0005 (near short-term trend)
Entry Mid: (Bottom + Top) / 2

Target Bottom: target1 × 0.999 (take profit level 1)
Target Top: target2 × 0.999 (take profit level 2)
Stop Loss: stopLoss × 1.005

Risk Points: EntryMid - StopLoss
Reward Points: TargetBottom - EntryMid
R:R Ratio: Reward / Risk

P&L for $1000 trade:
  Profit Estimate = 1000 × (Reward Points / Entry Mid)
  Loss Estimate = 1000 × (Risk Points / Entry Mid)

Plain English Instruction:
  IMMEDIATE: "Price is in buy zone RIGHT NOW. You can buy between $X–$Y immediately."
  NEXT_4H: "Wait for 4-hour candle ABOVE $Y, then buy. Don't buy before close."
  SELL: "Not good to buy. If holding, sell above $X."
  HOLD: "Do nothing. Watch for price to reach $X–$Y."
